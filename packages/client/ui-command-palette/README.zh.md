# @deepseek-ai/dsh-client-ui-command-palette

[English](README.md) | 中文

命令面板 UI 插件：浏览器半在 frame 级的 `shell.overlay` 槽里注册一个悬浮的 ⌘ 触发按钮。点击后弹出居中的、可过滤的命令列表；执行命令或点击遮罩关闭。主机半有意留空——面板不拥有任何主机工具、服务或持久状态；每条命令都通过对应包的 Context 合并触达现有客户端服务（`layout`、`workspaces`、`theme`）。

命令分三组——布局（切换侧栏、打开/关闭详情面板）、会话与工作区（新建会话、通过原生目录选择器添加工作区文件夹）、主题（浅色 / 深色 / 跟随系统）。过滤对命令标签做大小写不敏感匹配。命令失败被吞掉：启动器绝不能把错误暴露给模型。

所有颜色取自共享的 `--dsw-alias-*` 主题令牌，因此浮层会跟随当前主题及其浅色/深色方案。

## Model Experience

无模型可见影响：面板是纯展示层，不读写任何会话状态。

#### KV Cache effect

无。

## Known Limitations and Deferred Work

- **无键盘快捷键** —— 目前只能通过悬浮按钮打开；全局 Ctrl+K 绑定推迟到出现键盘快捷键席位之后。
- **文案硬编码为中文** —— 触发按钮和命令标签是字面量而非本地化字典；i18n 推迟。
